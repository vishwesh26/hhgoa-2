RAG Engine Architecture

A detailed breakdown of the Retrieval-Augmented Generation pipeline. Understanding vector embeddings, semantic search, and context injection for large language models.

01. INGESTION & EMBEDDING

Raw unstructured text is ingested and passed through the primary embedding model (default: text-embedding-ada-002). This process converts semantic meaning into high-dimensional vector representations. 

def generate_embedding(text: str) -> List[float]:
    response = client.embeddings.create(
        input=text,
        model="text-embedding-3-large"
    )
    return response.data[0].embedding

02. SEMANTIC SEARCH LOGIC

COSINE SIMILARITY

When a user queries the system, the query is embedded into the same vector space. The engine calculates the cosine similarity between the query vector and all stored document vectors, retrieving the top-K closest matches.

  • Query Encoding (10ms)
  • ANN Index Search (15ms)
  • Cross-Encoder Reranking (17ms)
